# `scene_builder.py` — MJCF Scene Generator

**Module**: `sim_demo/scene_builder.py` (240 lines)
**Purpose**: Generates MuJoCo MJCF XML from `config/sim_layout.yaml`. Defines world frame = robot frame. Models the full OpenMANIPULATOR-X with published dimensions.

---

## Layout System

The `Layout` class converts between pixel coordinates (from camera images) and metric coordinates (robot frame) using a single measured scale parameter.

| Constant | Value | Meaning |
|----------|-------|---------|
| `MAT_TOP` | 0.010 m | Green mat surface height |
| `BOARD_TOP` | 0.008 m | Socket board surface height |
| `MARKER_R` | 0.009 m | Calibration marker sphere radius |

## Generated Scene Structure

### World Geometry
- **Table**: 0.45 × 0.51 × 0.02 m
- **Green mat**: 0.125 × 0.125 m (peg placement area)
- **Socket board**: 0.036 × 0.125 m (4 sockets)
- **Socket markers**: Red outline rings + dark interior circles
- **Peg bodies**: Free-joint cylinders/prisms (mass ~80g, friction 3.5)

### Robot Kinematic Chain
```
robot_base (fixed)
  └─ link1 [joint1: hinge Z-axis]   ← Base pan
       └─ link2 [joint2: hinge Y-axis]   ← Shoulder pitch
            └─ link3 [joint3: hinge Y-axis]   ← Elbow pitch
                 └─ link4 [joint4: hinge Y-axis]   ← Wrist pitch
                      └─ gripper_base
                           ├─ finger_left [slide Y]
                           └─ finger_right [slide Y]
                      └─ tool_marker (magenta sphere on mast)
```

## Key Functions

### `build_scene_xml(layout_cfg, pegs, peg_xy, seed)`

Generates complete MJCF XML string. Includes:
- Contact exclusions (base ↔ link2/link3 to prevent self-collision)
- All geometry from one YAML config
- Random peg placement via seed

### `_prism_vertices(kind, r, h)`

Generates triangle/hexagon mesh vertices for non-cylinder peg geometry.

### `default_peg_xy(seed)`

Random peg placement in [0.11, 0.19] × [-0.09, 0.09] m (on the foam mat).

## Design Decisions

- **World frame = Robot frame**: Eliminates one transform from the calibration chain.
- **Scene generated by code (not static XML)**: All geometry derived from one YAML config. Each run stores the exact XML used for reproducibility.
- **Contact exclusions critical**: Without base ↔ link2/link3 exclusions, the shoulder cannot swing backwards (q2 < 0). The arm silently stops, causing tracking error exactly equal to |q2 target|.
- **Magenta calibration marker**: Sphere on a mast attached to link4 — optically detected by the calibration system. No physical equivalent exists on the real robot yet.
